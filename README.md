## Tunnelling informatics

The data-driven study of hydrogen tunnelling in enzymes:
[overview](https://sectio-aurea-q.github.io/tunnelling-informatics.html).

- **[MEG-NEN](https://github.com/sectio-aurea-q/meg-nen)**: a curated database of measured hydrogen isotope
  effects in enzymes, each value traced to its primary source. Under construction; the data note is
  [doi:10.5281/zenodo.24116484](https://doi.org/10.5281/zenodo.24116484).
- **[ELIAH](https://github.com/sectio-aurea-q/eliah)**: a reference for the Eckart tunnelling coefficient,
  checked against 1197 certified values.
- **The tunnelling fraction** η = 1 − 1/κ: the part of a reaction rate that exists only because of tunnelling
  ([page](https://sectio-aurea-q.github.io/hackfort-equation.html)).
- **[MEG-APSU](https://github.com/sectio-aurea-q/meg-apsu)**: a first structure-based classifier for tunnelling
  in enzymes; its accuracy and its limits are on [its page](https://sectio-aurea-q.github.io/meg-apsu.html).

## Number theory

- **[radix-rank](https://github.com/sectio-aurea-q/radix-rank)**: certified upper bounds for the analytic rank
  of elliptic curves, assuming GRH.

## Security research

- **[VÄRN-60](https://github.com/sectio-aurea-q/varn-60)**: timing tests for ML-KEM implementations, with
